## Change summary

- `CardPrice.tsx`: currency marker now renders **only** the known symbol; unknown currencies fall back to the code. The real code is kept as `title` and `aria-label` on the marker. Group/`wbr` algorithm, zero handling, and unknown-currency digit defaults are untouched.
- `SellingPrice.tsx`: compact mode no longer renders the `sale.actual` label. The full-detail branch is byte-for-byte unchanged.

## Semantic regression assertions

Assumes `useI18n` is mocked with `locale: 'en-US'` and `t: key => key`.

**CardPrice**

- **Known currency keeps code accessible, not visible**
  - `marker = screen.getByTitle('USD')`
  - `expect(marker).toBe(screen.getByLabelText('USD'))`
  - `expect(marker.textContent).toBe('$')` — no `USD` text in the visible marker.
  - Other visible amount text does not contain `USD`.

- **Unknown currency falls back to code**
  - Render `currency="ZZZ"`, `amount={10}`.
  - `screen.getByLabelText('ZZZ').textContent === 'ZZZ'`
  - `screen.getByTitle('ZZZ')` is the same element.
  - Does not throw on missing `currencies.ZZZ`.

- **True zero remains a value**
  - Render `amount={0}`, `currency="USD"`.
  - `screen.queryByText('rec.not_stated')` is `null`.
  - `.card-money` text contains formatted zero (`0.00` with USD defaults).
  - `.card-number-segment` elements exist.

- **Null / undefined stays “not stated”**
  - Renders `rec.not_stated`.
  - No `.card-currency` / no `aria-label` for the currency.

- **Grouping and `wbr` invariants**
  - Render a grouped amount such as `1234567` JPY with `locale='en-US'`.
  - `segments = [...container.querySelectorAll('.card-number-segment')]`
  - `expect(segments.map(s => s.textContent).join('')).toBe(fullFormattedString)` from the same `Intl.NumberFormat` options.
  - `expect(container.querySelectorAll('wbr')).toHaveLength(segments.length - 1)`.
  - This confirms complete groups are preserved and `wbr` only appears between them.

**SellingPrice**

- **Compact omits only the label**
  - `render(<SellingPrice product={product} compact />)`
  - `expect(container.querySelector('.card-price-label')).toBeNull()`
  - `expect(container.textContent).not.toContain('sale.actual')`
  - `expect(screen.getByLabelText(product.currency)).toBeTruthy()` — `CardPrice` still rendered.
  - Sale unit markup remains: `expect(container.textContent).toContain('/ ' + product.saleUnit)` when `product.saleUnit` is set.
  - Adjustment/period markup still renders when `priceAdjustmentId` is set.

- **Full detail markup unchanged**
  - `render(<SellingPrice product={product} />)`
  - `expect(container.textContent).toContain('sale.actual: ' + formatMoney(product.price, product.currency, locale))`
  - Unit suffix still appended in the full branch.
  - Adjustments/period text unchanged in both modes.
