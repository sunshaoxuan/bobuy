# REPORT-19 四语品牌与商家工作台验收

## 范围
- 对应 PLAN-60。商城、商家登录和后台统一品牌：宝宝败 / BoBuy / ボボバイ / 寶寶敗。
- 四语 UI 资源、插值、持久化、日期组件、请求语言和后端错误语言同步。
- 后台采用独立侧栏、顶栏和内容栅格，手机抽屉导航；行程维护桌面双列、手机单列，宽表格内部滚动。
- 商城保留 Pinterest 瀑布流、图片圆角、轻遮罩、半透明加购与匿名购物车。
- 采购页移除被既有租户安全边界关闭的全局钱包读取和失效展示，保留行程采购、结算和权限边界。

## 验证
- 前端全量运行：24个文件及其测试通过，另一个 i18n 文件内的文件系统扫描测试在 jsdom URL 环境失败。将该扫描改为独立 Node 检查后，最终 i18n 文件11项通过；其余有效结果复用，最终有效测试共83项。
- 781个四语资源键集合、非空值、插值一致性及日文关键资源内容测试通过。静态资源引用检查和故意缺失键负例通过，构建通过。
- 后端认证集成测试12项通过，包含四语错误响应。关闭 MessageSource 系统语言回退，确保英文请求在日文 JVM 上仍返回英文。五个生产服务打包通过。
- 商城真实本地容器浏览器回归：360、390、768、1440四视口加购、数量、购物车持久化和注册入口4项通过。
- 四语后台、像素测量、独立视觉复核及生产发布结果见下方最终验收。

## 最终验收
- 本地功能 PASS：四视口四语及九个后台页面检查通过，包含登录、退出、输入保留、购物车保留、日历与刷新。控制台及失败网络请求为0，详见 evidence/PLAN60/local/browser-report.json。
- 几何 PASS：280个控件满足预置44px热区、3px字形余量、min(2px,字形高度10%)中心误差；故意越界负例被拒绝。详见同目录 geometry-report.json。
- 视觉 PASS：最终1440英文行程整页、360日文行程整页、繁中抽屉及原尺寸表单局部均经主 Agent 查看。四语最终截图齐备；首次抽屉动画中间态证据已替换，360/390状态浮层和行程激活菜单补测通过，见 overlay-report.json。
- 外部复核：Gemini 3.8 Flash high 两轮真实截图复核。第一轮发现分页过强、手机顶栏拥挤、抽屉缺账户区及表格滚动提示弱，已修复并重新采图。第二轮无阻塞缺陷，要求补齐展开态证据，已补测。其简中品牌 OCR 误读经 DOM 与主 Agent 视觉检查排除，不作为实际缺陷。
- 生产：待发布20261023.2及 HTTPS、资源一致性、登录、四语、保护对象检查。

## 已知边界
- 商家未提供商品内容译文时显示原文；界面词条四语独立完整，不把原文商品数据当作缺失界面翻译。
- 生产注册、验证码发送仍受既有 SMTP、反滥用与恢复门禁限制，本次保持关闭。
- 本地使用已有 bobuy-local 容器组，生产使用已有 bobuy 容器组；无新增环境、无数据库结构变更。
