# Recommendation issue selection

The old issue directory used fragment anchors to scroll to an article while keeping both issues visible. It now provides a single selected-topic filter with a clear All entry; no topic selected shows every published issue. The topic selection is in `/recommendations?topic=<post ID>`, preserving existing node/other query context and same-route search state. Existing `/recommendations/<post ID>` article links continue to work. Topic switching closes a stale product-detail selection and drops a category absent from the new scope. Invalid categories in direct URLs are normalized with history replacement.

Category counts are computed from the topic and search scope **before** category filtering, so selecting a category does not erase the other choices or change their counts. Zero-count categories are absent, including Unclassified where appropriate. Existing public paginated feed requests are read through their final page; issue identity is deduplicated, never product identity, retaining separate occurrences and source offers across issues. Superseded node loads are cancelled logically before publishing their results. There is no customer supplier-filter control in the current UI; supplier visibility and any existing query context are preserved, with no invented supplier-selection behavior.

Local verification uses the existing shared frontend with read-only current-public GET replay and no stored content writes. Browser checks passed: All 152 / warehouse 122 / online 30; 17 / 14 / 11 nonzero category choices respectively (counts include Unclassified when present); stable choices after selecting a category; invalid category clearing on topic switch; refresh/back/forward; search retained across topic changes; distinct Vaseline source offers retained; desktop/mobile no page overflow; existing direct article route. Screenshots were inspected. Targeted helper/gallery tests 9 and affected recommendation-page tests 6 passed; normal TypeScript/Vite build passed with 1111 locale resources.

Evidence: [local browser](evidence/recommendation-topics/browser.json), [desktop category](evidence/recommendation-topics/desktop-category.png), [mobile selected topic](evidence/recommendation-topics/mobile-online.png). Production release and exact-candidate CI are pending at this checkpoint.

No real recommendation, product, price, stock, sales activation or registration content/configuration changed. The three proposed permanent cleanups and all real SMTP account/credential/configuration changes remain unapproved and untouched. The later requested encrypted administrator mail-settings feature is a separate subsequent batch; it is not part of this release.
