# REPORT-20 统一用户与多类型管理验收

## 范围
- 对应 PLAN-61。统一账号支持客户、商家或两者；购物车注册固定客户；独立注册支持类型多选。
- 平台管理员管理用户、类型、登录信息及启用状态；普通商家无全局账号管理权限。类型多选不授予平台管理员权限。
- 双类型用户通过客户专属 API 查看自己的购买记录，通过商家 API 查看自己销售业务。保留商家独立认可边界与四语品牌。

- V5 迁移演练 PASS：保留旧客户/商家账号、密码与订单关联；非法、空和重复类型集合负例拒绝；真实 pg_dump/pg_restore 恢复旧结构和数据；临时数据库清理。见 evidence/PLAN61/local/migration-report.json。
