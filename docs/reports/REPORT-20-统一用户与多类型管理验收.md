# REPORT-20 统一用户与多类型管理验收

## 范围
- 对应 PLAN-61。统一账号支持客户、商家或两者；购物车注册固定客户；独立注册支持类型多选。
- 平台管理员管理用户、类型、登录信息及启用状态；普通商家无全局账号管理权限。类型多选不授予平台管理员权限。
