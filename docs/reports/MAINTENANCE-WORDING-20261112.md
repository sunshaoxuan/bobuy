# 系统更新提示文案

目标：将维护期间的提示主体改为网站，覆盖独立维护页和应用内提示。用户授权验证后发布生产。

范围：简体、繁体及英文标题；日文现有标题已表明更新状态。保留交互和其他文案，不纳入其他功能改动。

方法：在当前主线隔离工作区修改文案，检查各语言及维护入口，运行相关静态验证与项目发布门禁，按现行发布流程核对版本和生产状态。

验收：维护页默认及简繁中文显示网站正在更新，英文显示网站更新；应用内对应语言一致；检查结果、发布状态及未完成事项记录于此。

生产候选基于 a3b0d17，匹配核查时的运行前端。主线账户布局属于并行修改，未纳入本次候选；此前基于主线的构建不作为此候选证据。
