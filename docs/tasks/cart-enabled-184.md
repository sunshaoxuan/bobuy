## 最终验收

- 迁移通过。PostgreSQL 17.11 在隔离测试库中启用 2/2 件商品，其中 1 件已软删。连续执行两次后原有字段逐行一致。H2 单测还验证了重跑保留商户后续手动关闭的状态。
- 后端通过 43 项相关测试。覆盖商户隔离、预览无写入、过期预览拒绝、批量确认、事务回滚、实际变更审计、公开商品投影及相关原有行为。
- 前端通过 28 项相关组件测试。最终改动后对应的 4 项入口与加购回归重新通过。类型检查和 1,967 个资源键检查通过。
- 浏览器功能通过。Chrome 使用本地 Vite 页面和合成接口数据，覆盖 390×844 英文、日文及简繁中文，1280×800 英文以及 767px 日文。开关可用空格操作，取消无写请求，确认按预览版本写入。桌面错误场景注入一次 409，刷新预览后成功。无未预期的控制台错误、应用异常或失败网络请求。
- 几何通过。开关、批量按钮及弹窗的确认、取消和关闭控件热区高度均为 44px。弹窗操作按钮相隔 8px，开关圆形滑块宽高一致。英文批量按钮字形纵向中心偏差 0.75px，各场景无页面横向溢出。
- 主 Agent 查看了双视口最终页面、开关、管理视图及弹窗裁图。工具栏入口完整，重复悬浮按钮的遮挡消失，日文长标题与关闭控件保持间距。双视口截图与计算样式见 [验收证据](../reviews/cart-enabled-184/)。本机 Sub2API 目录未提供 Gemini，视觉结论来自 Chrome 实拍及主 Agent 审阅。
- 交付边界为 GitHub PR，生产发布及生产数据验证属于后续工作。
