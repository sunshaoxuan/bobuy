# 首页与账户单一入口修正

## 授权范围与本批修改

- 仅修正顾客商城首页落地与账户入口：`/` 保留查询参数后进入 `/recommendations`；活动邮报与行程导航仍隐藏，`/products` 仍是可见的「好物推荐」。
- 移除手机底部快捷栏的账户重复入口，并在 `<=767px` 保留顶栏 `/account` 图标；不向侧栏或抽屉增加账户项。
- 覆盖四语既有 `store.account` 无障碍名称，不增加分类树、后台或其他导航工作。
- 将「开关隐藏的页面仍可作为默认落地」及「所有视口只保留一个顶栏账户入口」写入 UI/UX 标准。

## 最小验证集合

- 导航组件测试：四语下侧栏仍只展示获准入口，手机底栏只有商品与购物车且不含账户；顶栏账户链接由商城上下文测试核对。
- 商城上下文测试：`/` 保留节点查询参数并落至 `/recommendations`，活动邮报 flag 不影响默认落地；直接 `/recommendations` 继续可用。
- CSS/浏览器验收：390x844 与 1280x800 核对顶栏账户图标可见性、44px 触控目标、键盘焦点及底栏无重复账户；不检查未改区域。
- 静态检查：相关 Vitest、i18n、TypeScript 与 `git diff --check`。

功能与美观同时验收，须符合 `docs/ui-ux-guidelines.md`：
- 功能按本 issue 需求逐条通过，不改变未授权行为。
- 视觉与所在页面现有 UI 一致：复用已有 token 与组件，禁止原生未样式化控件，新控件与相邻控件齐高、同圆角档、间距统一。
- 具备默认 / hover / focus-visible / 选中或激活态；触控目标 >=44px；键盘可操作；有可见标签或 aria-label；对比度足够。
- 四语文案（含较长的 en-US / ja-JP）在窄屏不溢出、不重叠。
- PR 附 390px 与 1280px 的改动区域截图（含关键状态）。Playwright 可用则用现有脚本或一次性检查生成。
- 主移动断点 767px 及 390px 下布局正常换行，无横向溢出。
- 只运行与本次改动相关的最小测试；PR checks 通过。
