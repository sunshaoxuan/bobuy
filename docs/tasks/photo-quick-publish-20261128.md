# 现场照片批量快速上架（2026-11-28）

## 授权范围与实现

- 在商品档案增加供应商/市场级批次，商品行最多接收两张私有现场照片，并复用 Costco 照片识别队列。
- 只有带完整服务端决策追踪、四语名称/规格/介绍、准确货号、包装和叶分类的候选可自动建立并公开；客户端不提交事实或公开标记。
- 逐商品事务保存并经现有公开详情路径回读；同货号公开档案关联原 ID，私有/删除/多候选一律停止自动处理。
- 批次须由客户端在全部商品行登记后显式封批；封批且所有有效行真实公开后才建立独立官网图任务。找图结果仅为商家候选，不改变商品图库或可见性。
- V55 仅新增兼容表及索引；应用回退保留批次、私有证据和已公开商品，不回滚顾客写入。

## 最小验证集合

1. 前端四语资源一致性、TypeScript 类型检查和生产构建。
2. 后端定向编译/服务测试（环境可解析 Maven 依赖时）：照片批次权限与幂等、封批屏障、服务端事实准入、公开回读、独立找图消费和失败不下架。
3. 390×844 与 1280×800 的商品档案入口、上传行、缺项和批次状态截图；浏览器运行时不可用则如实记录，不以静态检查替代。

## UI/UX 标准验收条款

功能与美观同时验收，须符合 `docs/ui-ux-guidelines.md`：
- 功能按本 issue 需求逐条通过，不改变未授权行为。
- 视觉与所在页面现有 UI 一致：复用已有 token 与组件，禁止原生未样式化控件，新控件与相邻控件齐高、同圆角档、间距统一。
- 具备默认 / hover / focus-visible / 选中或激活态；触控目标 ≥ 44px；键盘可操作；有可见标签或 aria-label；对比度足够。
- 四语文案（含较长的 en-US / ja-JP）在窄屏不溢出、不重叠。
- PR 附 390px 与 1280px 的改动区域截图（含关键状态）。Playwright 可用则用现有脚本或一次性检查生成。
- 主移动断点 767px 及 390px 下布局正常换行，无横向溢出。
- 只运行与本次改动相关的最小测试；PR checks 通过。

## 外部与生产缺项

- 本开发任务不含生产发布权限；生产协调者需在目标环境核对照片模型固定节点、官网连接、V55 迁移和两个新增 worker 的实际启用状态。
- 官网图消费者只接受原 Costco 流程已经核验并持久化的官方图片证据；网站无结果或不可用时记录 `NOT_FOUND`，商品保持公开。

## 本次续修（固定起点 996293f）

- 官网图 worker 不再读取识别阶段的图片收据；只消费整批公开屏障建立的任务，并在消费时发起新的官方站点查找。Costco 页面必须由真实 SKU 页面提供，规格重量必须相同；例如 564513 的 330g/700g 不能作为 1.2kg 候选。
- 增加批次列表/重开、稳定批次与商品幂等键、原项补拍后服务端重新准入、移出、候选图状态与失败重试。批次到达 `PUBLISHED` 后仍继续轮询找图状态。
- 既有商品必须由服务端审核结果明确指向相同 ID，并同时核对供应商、四语规格和包装；首次已创建但公开回读待重试时复用记录的 `product_id`。
- 定向验收仍只覆盖本功能。实际 AI、官网及浏览器运行证据需要专用密钥/联网配置；本分支不访问生产，也不合并。
