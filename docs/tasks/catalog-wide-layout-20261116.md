# 商品目录宽屏布局任务指导

## 授权、基线与范围
用户授权改善带商品管理提示的 /products 目录宽屏利用率及加载量，保留桌面与移动体验。未见原始截图，依据用户描述及实际代码调查。基线由 git HEAD 记录；独立克隆，无既有脏文件。使用 bobuy-rapid-production 工作流。

## 本批修改与最小验证（实现前冻结）
- 仅含商品目录的 store-main 在 >=1920px 放开最大宽度，沿用32px边距、200px卡片最小宽度和16px列间距；其他页面不变。
- 目录会话初始宽度 >=1920px 时逻辑批次48件，其余24件。固定会话批次，调整窗口不改变分页偏移。两个24件服务端页顺序读取，校验版本/总量/大小/页码；现有 hook 校验聚合唯一性及完整性。排序、分类、搜索仍在服务端进行，身份变化重新从0开始。
- 不改后端，不减少总API请求数；352件的用户加载批次从15降至8。销售报价继续24件一批。
- 最小检查：新增聚合分页测试、现有目录排序与自动加载测试；一次前端构建；浏览器2580×1440、1280×800、390×844及320×800，排序/分类/加载、详情暂停、console/network、计算样式、整体与原尺寸局部截图。需要时使用明确标记的合成352件数据，不写生产。
- 主Agent查看最终图片；实际Gemini入口不可用则明确欠缺，不声称通过或绕过发布。没有发布凭据时保留候选和证据，不擅自发布。

## 标准验收条款
功能与美观同时验收，须符合 docs/ui-ux-guidelines.md：
- 功能按本 issue 需求逐条通过，不改变未授权行为。
- 视觉与所在页面现有 UI 一致：复用已有 token 与组件，禁止原生未样式化控件，新控件与相邻控件齐高、同圆角档、间距统一。
- 具备默认 / hover / focus-visible / 选中或激活态；触控目标 ≥ 44px；键盘可操作；有可见标签或 aria-label；对比度足够。
- 四语文案（含较长的 en-US / ja-JP）在窄屏不溢出、不重叠。
- PR 附 390px 与 1280px 的改动区域截图（含关键状态）。Playwright 可用则用现有脚本或一次性检查生成。
- 主移动断点 767px 及 390px 下布局正常换行，无横向溢出。
- 只运行与本次改动相关的最小测试；PR checks 通过。
