# 商品多分类候选（2026-11-24）

## 授权与本批修改

以仓库可用的 `main` 提交 `f7c7caf8` 为基线；当前检出环境未配置 Git remote，无法联网更新引用。仅实现商品分类关系、商品主档多选入口及顾客端分类投影：保留现有主分类表，新增受外键和唯一键保护的附加分类表；事务内保存完整集合并以版本拒绝过期写入；顾客端按任一分类及祖先匹配并按 SKU 去重。不触碰生产数据、发布状态、价格、库存或历史推荐快照。

迁移是纯增量：部署执行 `V52__product_additional_category_paths.sql`。应用回滚时旧版本继续读取原主分类表；数据库回滚应先停用写入新关系的候选应用，再删除 `bb_product_additional_category_path`，最后删除 `bb_product_primary_category_path.category_revision`。迁移不改写已有商品行。

## 最小验收集合

- 后端针对性单测：旧主路径保留、多分类跨分支、重复/非法节点、清空、主分类替换、版本冲突、事务回滚、权限、移动跟随及删除保护。
- 顾客端投影单测：任一关联及祖先可筛选，统计与同一筛选结果按 SKU 去重，跨栏目允许各出现一次。
- 前端针对性测试：完整路径多选、移除、指定主分类、保存重开和冲突保留输入。
- 迁移检查：正向执行、外键/唯一约束及显式回滚步骤。
- UI 按 `docs/ui-ux-guidelines.md` 第 8 节验收：功能与美观同时验收，复用现有 token/组件和完整交互态；触控目标至少 44px；四语窄屏无溢出；在 390×844 与 1280×800 截图并核对计算样式；只运行本次最小相关测试。
