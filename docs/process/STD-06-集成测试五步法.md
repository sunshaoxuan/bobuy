# STD-06: 集成测试执行范围

更新日期：2026-11-12。适用于需要运行环境的集成验收。

1. 确认受影响行为、候选身份、所需服务和现有环境。优先复用已有 Bobuy 本地栈。端口占用先核对归属；仅在确有冲突且属于本任务时处理。
2. 合并本批必要静态检查与针对性测试。复用匹配源码、依赖、配置、命令和环境的有效结果。已有门禁运行时跟踪该运行；新增检查须说明其发现的具体风险。
3. 仅在缺少所需环境或运行版本不匹配时启动或更新受影响服务。普通文档、CI配置和纯单元测试无需启动业务栈。
4. 验证变化的正常行为、相关边界和错误拒绝路径。UI变更依据实际运行页面完成浏览器、控制台、网络、响应式及截图验收。数据迁移验证适用的幂等性、兼容与恢复约束。
5. 删除本任务临时数据与产物。任务独享临时服务可停止；共享环境按现有协调约定保留。缓存清理须有损坏或容量证据及明确目标。

原文要求每次 Start/Verify/Test 都调用 `std_06_integrated_test`，并无条件清场、启动完整环境和结束时停止全部节点。这些要求自本修订起撤销。当前可用技能由会话技能目录确定。

测试范围与命令见[当前测试矩阵](../reports/TEST-MATRIX-本地与CI执行矩阵.md)。安全、权限、数据保护和真实运行验收按变更范围保留。
