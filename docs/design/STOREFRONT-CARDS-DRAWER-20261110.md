# 商品卡、期次抽屉与焦点行为

基线：a16af01e（现役 20261110.2 前端），core 48433，V28.1。日期真实性、来源标签、隐藏节点选择器和正文保稿保持。

## 需求与显示规则

- 本程好物和好物推荐沿用现有品牌视觉；同一网格行商品卡等高，品名固定两行占位，完整名称仍供辅助技术、详情和标题提示读取。此要求替代旧 Pinterest 文档中卡片品名不限行的规定，详情不截断。
- 实际价格突出，来源在卡片下方小字展示；缺价不造零、历史参考价不冒充实时售价，现有购买权限不变。
  大字仅用于金额；“参考售价（非实时）”／实际售价标签、单位、条件和来源采用次级小字。不能将整段带标签／单位的价格句子放大。推荐卡规格与现有主档卡一致最多两行，完整规格仍在详情和可访问文本内保留。
- 商品档案评分为空且默认不公开；评分是商家维护的档案信息，不是用户评论统计。仅有效评分和显式公开许可同时具备时展示，旧数据保持隐藏。模型、保存、恢复和公共投影必须一致，不能将用户账户评分当商品评分。
  采用独立 `bb_product_rating` 表：0–5、半星步长、允许空值、显式公开、独立修订号／审核时间。复用商品所有权与商品行锁，档案内独立审核保存。旧商品文案及 JSONB 恢复记录不加字段，主档文案恢复不修改评分；公共读仅取同商家已公开商品的显式公开评分。V28.2 仅建新表，无旧数据回填。旧应用忽略新表的兼容性仍须实际证明，不能从加表推断启动／恢复已过。
- 右侧浮动按钮在手机和桌面打开右侧期次抽屉；默认关闭，不保留大菜单占位。关闭、遮罩、Escape、选期后收起和焦点返回由标准 Drawer 支持。按钮避开底部快捷导航及安全区。
- 期次顺序与日期显示仍使用已审期次日期／真实 JST 发布日期规则，不从标题、更新时间或本机日期猜填。

## 加载与焦点

列表失焦／重新可见不意味着数据发生变化，不触发分页重置或重拉。保留显式刷新、数据版本冲突提示、身份变化和真实日本日期变更。商品页仍按已激活区段和分页加载；期次元数据只在首次打开抽屉时请求，关闭后保留页缓存，切换真实查询／身份才失效。

已证根因：PublicProductCatalog 的 visibilitychange 调用 refreshCatalog；RecommendationBrowse 的同类监听调用 restart，刷新身份随后重置 useBrowsePages。不是这两处执行 location.reload。

## 验证与边界

针对两列表多次 blur/focus/visibilitychange、真实日期改变、手动刷新、分页／筛选／购物与草稿保留；抽屉默认关闭、首次加载、关闭重开不重拉、选期与 Back/Forward、唯一当前项、日期语义和长目录。最终正式包四语手机／桌面真实可见验收不可用 DOM 测试替代。
