# 商品排序、点击热度和用户星级任务

## 目标及用户补充
在本程好物和好物推荐列表右上提供价格、评分和人气双向排序。每次商品点击分别累计热度，重复点击重复计算；卡片右下显示小火苗及热度。评分使用用户星级平均值，悬停预览、点击选择，取消手工数字输入。用户后续明确要求持续完成数据库、并发、关联变化、卡片同步、测试和真实页面视觉验收，发现问题直接修复。

## 方法和归属
- 服务端先对完整筛选结果排序，再分页，每页 24 项。支持分类、搜索、商家、本程栏目、当前/历史推荐及选定期数。价格优先使用卡片有效销售报价，其余使用来源参考价；复用 ProductSaleService。同币种排序，币种分组，不推定汇率。排序输入变化使旧续页返回 409 并要求刷新。
- 点击采用 PostgreSQL 原子 UPSERT。照片、名称及普通卡片内容打开详情时计一次；购买、评分、完整热度提示及弹窗操作不增加详情点击。接口与前端使用字符串及 BigInt 保留精确值，大数紧凑显示并可查看完整整数。
- 点击及评价归属于操作时的商品主档 ID。同一商品跨栏目/多期卡片共享指标。推荐改绑后读取新商品指标，旧商品保留历史记录，关联变更不搬移或合并不同商品的评价及点击。
- 复用每账户每商品一份评价、1 至 5 分半星步进、版本冲突拒绝与均值计算。使用 Ant Design Rate 悬停和键盘交互。公开指标无个人资料泄露，匿名评分返回 401。
- 同页实例及跨标签页同步，迟到读取不能把计数回退或写到另一商品。React Portal 中的打星不触发卡片详情。

## 固定视觉预算
视口 1440、768、320 像素，DPR 1。可见字形/星形到背景可用内框至少 3px；居中控件中心误差不超过 min(2px, 字形高度的10%)；相邻操作热区至少 6px；手机主要操作高度至少 44px。排序文字左对齐且垂直居中，热度状态右对齐。星级实际 radio 热区 32×50px。文本域采用 3 个完整 24px 行框，可见内高 72px，外层 showCount 组件负责边框；滚动条区域单独保留，滚动起点/终点均检查完整行与字形余量。

## 已处理失败及证据失效
1. 旧工作目录与主线及迁移版本冲突，旧草案结果全部作废，转到当前主线。
2. Ant Design Select 的新增渲染触发 JSDOM 选择器错误，采用原生 select；受影响测试通过后执行最终前端全量。
3. 固定重启等待遇到 502，改为健康就绪轮询。
4. 原本地镜像 ID 在重建后不可解析。从保留镜像历史层取回与原回执 SHA256 完全一致的原 JAR，重建恢复镜像并恢复服务。驱动现先验证可执行原镜像、备份实际 JAR，复原时再核对 JAR 及两个数据库指纹。
5. 撤销旧星形居中结论，修复约 9.4px 偏差；大数折行改为紧凑显示、完整值提示；补足空星对比与未修改保存提示。
6. 2000 字边界补验发现文本框拖拽、滚动示能及半行显示问题。固定完整行几何，移除 resize，增加可见滚动条和提示，并真实验证首尾位置。
