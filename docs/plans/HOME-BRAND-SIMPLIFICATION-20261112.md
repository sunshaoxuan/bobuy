# 首页介绍区与品牌标识调整

## 目标与用户要求
删除截图红框内的首页介绍区。在页面左上角 LOGO 与宝宝败文字下面增加 bobuy.cc。保持现有商品、推荐、导航和搜索功能。

## 方法、范围与边界
从最新主分支建立独立候选，核对实际线上版本。仅修改首页介绍组件、品牌标识及必要样式和相关测试。保留其他工作区改动。无业务数据、数据库、认证或外部网关配置变更。局部实现由主 Agent 完成，真实运行截图提交 Gemini 独立视觉复核。

## 步骤与验证
1. 确认源码位置、当前运行环境、生产基础版本与发布门禁。
2. 删除首页介绍区及过时代码，添加品牌网址，完成相关静态检查与测试。
3. 运行真实页面，检查桌面 1440px、手机 390px 与最窄 360px。检查首页首屏、品牌返回首页、搜索、控制台及网络，保留整体和品牌原尺寸截图。
4. 冻结候选，按项目必要门禁提交和发布，核对生产实际资产及页面。记录实际执行结果和未完成项。

## 实现前验收预算
品牌作为整体首页链接，网址置于 LOGO 与名称组合下方，左对齐并保持同一视觉组。网址字号至少 11px；字形到可用内框各边至少 3px；有居中设计的字形视觉中心偏差不超过 min(2px, 字形高度的 10%)。移动端热区高度至少 44px，相邻操作热区间距至少 6px。保留既有页头栅格和搜索区域，不出现溢出、裁切、重叠或删除介绍后残留空白。
