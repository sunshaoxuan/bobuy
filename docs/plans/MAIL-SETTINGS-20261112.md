# 邮件设置可用性与视觉修复

## 目标与范围
用户反馈邮件设置不可测试、不可编辑、排版不合格。本批修复邮件设置表单、状态说明、保存与测试反馈及桌面和手机布局。以 main ecf1d09 隔离工作树实施，保留根目录无关改动。检查生产页面与现有本地栈，不新增 Docker 栈。

## 方法
追踪表单、API、服务端加密与测试收件人政策。基础配置可编辑并保存；密码与发送依赖受保护服务器配置。保留密码加密、管理员权限、目的地和收件人限制。生产凭据创建、密钥注入、注册开放及真实外部邮件发送需明确授权。

## 完成标准与验证
1. 清晰呈现加载、失败重试、未保存、已保存、缺少前置条件及测试结果。
2. 编辑、校验、保存重载、恢复设置、测试可用与禁用状态均有行为证据，避免误报发送成功。
3. 桌面 1440、窄屏 390 和 320 像素验证。两列基础配置与测试侧栏，手机单列；页面安全边距至少16px，区域间距24px，字段间距20px。主操作44px高，热区间距8px；文字内边距至少3px，字形中心偏差最多 min(2px, 字高10%)。
4. 最终运行整体图与局部图、控制台、网络、响应式和 Gemini 图片复核。功能、几何、视觉分别判定。
5. 合并前端测试、i18n、构建及相关后端检查；纯前端变更复用后端证据。冻结后不纳入其他任务。

## 当前证据
main 中 MailSettings.tsx 使用纵向无分区表单；密钥缺失时禁用密码和启用开关；测试依赖持久密码、批准收件人与无未保存修改。生产页已只读打开，需进一步核实真实渲染。
