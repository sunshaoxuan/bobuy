# PLAN-63 区域送货行程与自动流程

## 主目标与要求
- 2026-10-25：行程服务一个区域，移除车辆容量上限和固定起点、终点要求。
- 对外只公布送货日期，统一替换出发日期、执行日期语义。
- 状态根据实际业务流程自动变化，创建与编辑不提供状态选择。
- 代购员为当前账套管理员，不要求编号；同账号多个独立登录会话并行使用。
- 保留完整角色权限机制与账套边界，当前管理员具备本账套完整业务功能；细粒度授权后续优化。

## 方法、批次与边界
1. 核对模型及全部引用、流程、会话和相关文档。主 Agent 决定迁移、状态规则与安全边界。
2. 有界批次同步后端、版本化幂等迁移、前端、四语、测试和需求/API文档。外部模型仅提供最小上下文建议。
3. 廉价前检后冻结候选，共享后端正式测试与前端测试/构建，避免按子项重复全量。
4. 使用现有本地目标环境验收功能、Console、网络、响应式和真实截图，Gemini复核截图。
5. 本次不发布生产、不修改远端数据或认证网关。保留现有未跟踪产物，遵守仓库提交门禁。
