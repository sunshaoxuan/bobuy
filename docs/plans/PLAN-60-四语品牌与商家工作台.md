# PLAN-60 四语品牌与商家工作台

## 主目标与范围
- 2026-10-23：商城和 /admin 统一四语品牌，简中「宝宝败」、英文「BoBuy」、日文「ボボバイ」、繁中「寶寶敗」。文案通过 i18n 资源维护，语言切换持久化并同步 HTML、组件库和请求语言。
- 修复用户截图中的后台纵向错位，以专业运营工具的导航、内容栅格、表单和表格重建响应式后台。商城保留 Pinterest 商品瀑布流、轻遮罩、小型半透明加购及匿名购物流程。
- 复用唯一 bobuy-local 容器组。按既有授权发布至同一 bobuy 生产容器组，保留注册/邮件发布门禁、商客权限和其他应用热备/休眠状态。
- 非目标：业务数据变更、账户权限变更、新环境、新 AI 功能、网关配置治理。

## 方法
1. 定位 Layout 结构与 CSS，审计既有三语资源和商城硬编码。读取 i18n 规范及发布约束。
2. 主 Agent 实现与验收；调用已验证可用的 Claude 获取有限设计建议，实际页面截图交给可用 Gemini 复核。外部失败按规则降级，秘密不进入提示词。
3. 补齐四语词条、品牌、语言选择和组件库语言，明确商品内容缺少译文时的展示策略。调整后台 shell、登录、行程表单及通用内容约束。
4. 单元测试、构建、真实容器浏览器功能/控制台/网络/响应式及截图检查，更新需求与规范，提交版本管理。
5. 生产发布前记录保护对象快照；发布仅作用于本应用，检查 HTTPS、品牌、四语、登录、布局、保护快照一致性。

## 预置验收预算
- 视口 360x800、390x844、768x1024、1440x1000；四种语言及最长菜单文案、开关菜单/语言菜单、空数据和测试数据状态。
- 桌面导航 232px，内容区 minmax(0,1fr)，内容从顶栏下方开始。768px 以下抽屉导航；页面横向无溢出，宽表格仅在表格内滚动。
- 页面安全边距手机16px、平板24px、桌面32px；主要区域间距24px，紧邻工具间距8px。
- 主要交互热区至少44px高，相邻热区至少6px；字形至可用内框至少3px，居中误差最多 min(2px,字形高度10%)。对齐以实际字形及截图为依据。
- 内容标题、说明、表单、状态和操作分区清晰，表单桌面双列、手机单列。运营页面采用白/浅灰、中性墨色，保留适量品牌色和业务状态色。
