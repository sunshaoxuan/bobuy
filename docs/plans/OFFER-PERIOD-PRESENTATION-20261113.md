# 惠标签提示与优惠期间表达

## 主目标与范围
用户要求鼠标放在惠标签时从图标右侧展开文字并显示优惠期间，同时将商品详情中的工程式日期改为普通用户容易理解的表达。保留已上线热度右上角、名称列LOGO、实际优惠事实、价格与业务数据。

## 方法与冻结范围
局部前端修改：ProductMarkerBadges及其日期格式帮助模块、public catalog直接调用、标签样式与针对性测试。复用Ant Design Tooltip，优先向右展开，窄屏按现有组件规则避让边缘；支持悬停、键盘焦点及触屏点击。列表尚无完整优惠价格事实，首次打开提示时使用现有只读productDetail接口读取，单卡缓存，禁止预取全目录或新增后端接口。仅当有效PROMOTION事实支持时显示日期，未知明确写“优惠时间待确认”，失败显示可理解的重试提示。

日期按日本本地优惠日解释。日期型结束日包含当天，显示如“优惠期间：11月2日至11月15日”；跨年保留年份。精确时间型保留必要时间并用“日本时间”说明，不展示ISO、箭头、JST或整串零秒。非零秒如影响截止仍保留。详情与悬停复用同一格式。避免悬停/点击标签误打开商品详情或增加热度。

## 验收预算与最小检查
文字距提示可用内框四边至少3px，提示与图标至少6px，字形无裁切；长期间/多期间换行，不超视口。维持既有惠图标与商品图片、编号、热度位置；移动主要操作保持既有44px预算。1400级桌面与320px最窄视口覆盖悬停、焦点/点击、详情、未知及读取失败状态，必要长文字作为本地合成响应，真实数据与合成证据分开。

只运行标签/日期相关针对性测试、必要前端构建一次、相关浏览器功能/控制台/网络/截图与Gemini复核，跟踪原生CI；不跑全项目或后端测试。候选冻结后只因具体失败或相关输入变化最小修复，重跑先记录理由与可复用PASS。预计实施与本地验收5至10分钟，CI与发布跟踪原运行。发布只替换前端，核对当前线上基线、回退镜像与实际资产，线上检查相同区域。通过即交付。
